┌───────────────────────────────────────────────────────────────────────────┐
│ 4. DISCREPANCY DETECTION PATTERNS                                         │
└───────────────────────────────────────────────────────────────────────────┘

C_PANIC_RUST_ERR (🚨 CRITICAL)
  → C crashes/panics
  → Rust safely rejects with Err
  → PRIMARY SECURITY WIN
  → Memory safety vulnerability prevented

C_PANIC_RUST_OK (⚠️ HIGH)
  → C crashes/panics
  → Rust successfully parses
  → C is too fragile

C_OK_RUST_ERR (⚠️ MEDIUM)
  → C accepts (false positive)
  → Rust rejects as invalid
  → C is too permissive

C_NULL_RUST_OK (ℹ️ LOW)
  → C returns NULL (reject)
  → Rust succeeds
  → C is overly conservative
