The script looks for these key patterns:
1. "Test unit written to ./crash-XXXXX"  ← Most common
2. "0x7b,0x22,0x6e,..."  ← Hex dump of crash input
3. "artifact_prefix='./'"  ← Path where crash file was saved
4. "Base64: eyJuIj..."  ← Base64 encoded input (sometimes)
